أكاديمية ساندس الوطنية

كيف يعمل اللقاء
١) الشاشة الكبيرة تعرض باركود مرة واحدة في الافتتاح.
٢) الطلاب يمسحون ويُبقون الصفحة مفتوحة. لا يفتحون ملفات.
٣) كل ضغطة «التالي» تفتح السؤال على الجوال ١٢ ثانية.
٤) أثناء العدّ تتحرك النسب على الشاشة. ثم يُقفل الباب ويعلّق الضيفان.

التشغيل المحلي
- python serve.py
- الشاشة: http://عنوان-الجهاز:8780/
- باركود البداية يشير إلى /vote.html على نفس الشبكة.

GitHub + Google Apps Script (للهواتف على بيانات الجوال)
١) ارفعوا المشروع على GitHub وفعّلوا GitHub Pages.
٢) انسخوا ملفات مجلد gas إلى script.google.com
   نشر → تطبيق ويب → أي شخص.
٣) ضعوا رابط /exec في js/data.js داخل SHOW.vote.gasUrl
   وضعوا رابط الصفحات في SHOW.vote.pagesUrl إن أردتم الباركود يشير إليها.
٤) الباركود في الافتتاح يفتح تطبيق التصويت مرة واحدة.
